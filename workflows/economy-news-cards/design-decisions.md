# 디자인 결정 기록

## 출발점

처음 만든 카드에는 여러 뉴스와 장식 요소가 한 화면에 같이 있었다. 제목의 우선순위가 약했고, 숫자는 읽기 전에 설명을 찾아야 했다. 이 상태에서는 스토리를 넘기는 사람에게 전달할 문장이 없었다.

## 레퍼런스에서 가져온 원칙

참고한 인포그래픽은 굵은 제목, 분명한 강조색, 읽는 순서가 보이는 데이터 표현을 사용했다. 그 특징을 그대로 베끼지 않고 아래의 작업 규칙으로 바꿨다.

| 관찰 | 적용 규칙 |
| --- | --- |
| 첫 시선에 결론이 보임 | 제목은 2줄 이내, 키워드 한 구절만 마커 처리 |
| 수치가 그래프의 주인공 | 큰 수치 1개와 비교값 2개만 노출 |
| 정보 묶음이 분리됨 | 헤드라인 → 수치 그래픽 → 생활 영향 → 출처 순서 |
| 색이 의미를 구분함 | 기본 종이색은 고정, 포인트 팔레트만 매주 순환 |

## 고정 요소

- 1080×1920 세로 캔버스, 크림 배경, 흰 종이 패널, 검정 테두리
- `이번 주 경제 한 장` 시리즈명과 날짜 범위
- 굵은 한글 제목, 수치가 읽히는 막대/비교 블록
- 하단의 `그래서 우리한텐?`과 원출처·발표일

## 매주 바꾸는 요소

`green-coral → teal-orange → olive-terracotta` 순으로 한 주에 한 팔레트만 쓴다. 이전 주와 같은 색을 반복하지 않는다. 뉴스별로 색을 랜덤하게 바꾸지 않는다. 시리즈의 기억점은 유지하고, 새 주라는 신호만 준다.

## 이미지 생성 시안을 기본 경로에서 뺀 이유

이미지 생성은 분위기와 삽화에는 빠르지만, 경제 카드에서 필요한 한글 문장·축·수치·단위·정렬을 반복적으로 동일하게 보장하기 어렵다. 품질은 예쁜 한 장보다 같은 구조를 다음 주에도 깨지지 않고 뽑는 데서 나온다. 따라서 표·그래프·텍스트는 코드로 그리고, 삽화가 필요할 때만 이미지 모델을 보조로 쓴다.
