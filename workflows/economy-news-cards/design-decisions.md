# 디자인 결정 기록

## 기준 모듈

현재 기준은 2026-09-17 Fed 샘플에서 승인한 생활 영향 중심 카드다. 굵은 제목 다음에 확인된 변화와 필요한 근거만 보여주고, `그래서 우리한텐?`에서 지출·대출·저축·투자·일자리로 이어지는 경로를 설명한다. 카드 수는 1~5장이며 뉴스 하나가 한 장을 차지한다.

## 레퍼런스에서 가져온 원칙

참고한 인포그래픽의 굵은 제목, 분명한 강조색, 읽는 순서를 아래 작업 규칙으로 바꿨다.

| 관찰 | 적용 규칙 |
| --- | --- |
| 첫 시선에 결론이 보임 | 제목은 2줄 이내, 키워드 한 구절만 마커 처리 |
| 근거가 빠르게 읽힘 | 기사에 필요한 수치·비교·설명만 선택 |
| 정보 묶음이 분리됨 | 헤드라인 → 확인된 변화 → 생활 영향 → 출처 순서 |
| 색이 의미를 구분함 | 기본 종이색은 고정, 포인트 팔레트만 주차별 순환 |

모든 이슈를 큰 숫자 하나와 비교값 두 개로 만들지 않는다. 정책 결정이나 전달 경로가 핵심이면 짧은 설명과 영향 행이 더 적합하다.

## 고정 요소

- 1080×1920 세로 캔버스, 크림 배경, 흰 종이 패널, 검정 테두리
- `이번 주 경제 한 장` 시리즈명과 날짜 범위
- 굵은 한글 제목과 분명한 정보 순서
- 하단의 `그래서 우리한텐?`과 원출처·발표일

## 주차별 요소

`green-coral → teal-orange → olive-terracotta` 순으로 한 주에 한 팔레트만 쓴다. 같은 주의 카드는 같은 팔레트를 쓰고, 다음 완료 주차에서 순서를 넘긴다.

## 제작 경로

표, 그래프, 문장, 수치, 단위, 정렬은 Skill에 포함된 HTML/CSS/JavaScript 렌더러로 만든다. 이 경로가 현재 기준이며 1~5장에 대응한다. 이미지 생성은 코드 도형만으로 설명하기 어려운 새 삽화가 필요할 때만 보조로 쓰고, 사실 텍스트는 렌더러에 남긴다.

[2026년 9월 9~13일 3장 결과](examples/2026-09-09_to_13/)는 당시 디자인의 역사 기록이며 현재 템플릿 기준은 아니다.
