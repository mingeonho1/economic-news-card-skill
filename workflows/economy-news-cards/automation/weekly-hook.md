# 주간 자동화 훅

수요일 오후 8시, `Asia/Seoul`에 제작을 시작한다. 오후 8시 수신으로 운영하려면 먼저 제작·검증을 끝내고 8시에 전달하도록 실행 환경을 설정한다. [전달 방식과 준비 조건](delivery.md)을 함께 읽는다.

## 실행 계약

1. 완료된 주간 실행의 `manifest.json`과 출처 기록을 읽는다. 직전 완료 주간의 다음 날부터 7일을 잡는다. `2026-09-09~09-15 → 09-16~09-22 → 09-23~09-29`처럼 이어간다. 누락된 주간을 합치거나 건너뛰지 않으며 아직 끝나지 않은 기간은 만들지 않는다. 완료 로그가 없는 최초 실행만 가장 최근에 끝난 수요일~화요일을 선택해 기준을 기록한다. 샘플·부분 실행은 주간 종료일을 앞당기는 근거로 쓰지 않는다.
2. 공식 원문을 우선해 후보를 수집한다. 지수 나열보다 사람들이 관심을 가질 변화와 생활에 미치는 영향을 우선한다. [선정 기준](../../../skills/weekly-economy-cards/references/market-selection.md)을 적용해 검증된 뉴스 **1~5개**를 선택한다. 통과한 후보가 없으면 억지로 채우지 않는다.
3. 발표 시각과 시간대, 한국 날짜, 지표가 다루는 기간을 구분한다. 대상 주간 안에 실제 발표·발생한 사건인지 확인한다. 미국 발표의 현지 날짜와 한국 날짜가 다르면 둘 다 기록한다. 기사 작성일만으로 포함하지 않는다. 각 주장에 원문 URL, 단위, 비교 기준, 계절조정 여부, 잠정/확정 여부를 연결한다.
4. 완료본뿐 아니라 이미 전달한 샘플·부분 실행의 주제도 대조한다. 같은 사건은 반복하지 않으며 새로운 결정·수치가 나온 후속 이슈만 달라진 점을 명시해 다룬다.
5. 뉴스당 1080×1920 PNG 한 장을 만든다. 큰 제목, 핵심 사실, `그래서 우리한텐?` 영향 1~2줄을 기본으로 하고 필요할 때만 항목을 나눈다. 환율·대출·주가에 미치는 영향은 조건과 시차를 밝혀 단정하지 않는다. 계산 예시는 실측치와 구분한다.
6. 디자인 구조는 고정하고 `green-coral → teal-orange → olive-terracotta`의 포인트 색만 주간마다 순환한다. 직전 완료 주간의 팔레트를 확인한다. 샘플 제작은 순환을 진행시키지 않는다.
7. `runs/YYYY-MM-DD/`에 선택한 수만큼의 PNG, 렌더 입력, `sources.md`, `provenance.md`, `manifest.json`, ZIP을 저장한다. 모델·도구는 실제 실행한 값만 기록한다. HTML 렌더를 GPT Image 생성이라고 적지 않는다.
8. 수치·문구·이미지 잘림을 확인한 뒤 완료 상태를 기록한다. 생성 알림에는 개별 PNG와 ZIP 다운로드 링크를 넣는다. 카카오톡 전송은 인증·공개 이미지 URL·다운로드 링크가 준비된 경우에만 실행하고 별도 전송 영수증을 남긴다.

## 중단 조건

아래 중 하나라도 확인하지 못하면 해당 뉴스는 버리고 다른 후보로 바꾼다.

- 원문 기관과 URL
- 수치·단위·기간·비교 기준
- 대상 기간에 해당하는 실제 발표·발생일과 시간대
- 카드 문구와 출처 기록의 일치

## 자동화 프롬프트에 넣을 본문

```text
설치된 weekly-economy-cards Skill을 읽고 주간 경제 카드를 제작한다. 직전 완료 주간의 다음 날부터 7일을 대상으로 하되, 아직 끝나지 않은 미래 기간은 완료본으로 만들지 않는다. 이미 전달한 샘플과 부분 실행까지 읽어 사건 중복을 확인한다.

시장 지수의 나열보다 사람들이 관심을 가질 변화와 생활에 미치는 영향을 우선한다. 공식 발표 원문에서 사실·수치·비교 기준·시각·시간대를 확인하고, 대상 기간에 발표되거나 발생한 이슈 1~5개를 고른다. 기사 날짜와 지표 기간을 사건 날짜로 착각하지 않는다.

뉴스마다 1080×1920 PNG 한 장을 만들고 승인된 큰 제목과 흰 패널 디자인을 유지한다. 포인트 색만 green-coral, teal-orange, olive-terracotta 순서로 바꾼다. 사실과 '그래서 우리한텐?'을 쉽게 쓴다. 영향은 조건부 설명으로, 계산 예시는 가정으로 표시한다. 실제 사용한 모델과 렌더 도구를 provenance에 기록한다.

PNG 원본, 출처, manifest, ZIP을 저장하고 사실검증과 이미지 검수를 마친 후 다운로드 링크를 제공한다. 카카오톡이 인증·설정되었다면 검증된 결과의 공개 이미지 URL과 원본 다운로드 URL로 dry-run을 통과한 뒤 나에게 보내기를 실행한다. 미연결 상태는 전송 완료로 보고하지 않는다. 실패나 모호한 응답은 기록하고 중복 발송하지 않는다.
```

반복 실행 등록은 사용 중인 앱의 자동화 기능을 이용한다. 이 문서나 Skill 설치만으로 일정·계정 연결이 생성되지는 않는다. [카카오톡 연결 방법](../../../integrations/kakao/README.md)을 참고한다.
