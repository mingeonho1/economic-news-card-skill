# 카드 렌더러

이 폴더를 작업 디렉터리로 복사한 뒤 `data.js`의 `cards` 배열에 1~5개 항목을 넣는다. 각 카드에는 사실, 조건부 생활 영향, 출처 표기를 담고 `./render.sh`를 실행한다.

렌더러는 Chrome Headless로 `output/weekly-economy-01.png`부터 차례로 만들며, 1080×1920 크기·텍스트 넘침·상하 200px 안전 여백을 검사한다. 이전 실행의 PNG는 시작할 때 지워서 현재 배열에 없는 카드가 결과로 남지 않게 한다.

기본 `data.js`는 승인된 Fed 샘플이며 실제 주간판이 아니다. 새 실행에서는 검증한 원문과 해당 주차의 색상으로 교체한다.
